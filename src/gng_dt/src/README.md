# 将来的な問題

coeffRef(i,j) = 0 は値を0にするだけで、内部データ構造から要素を削除しない。削除されたエッジが「ゴミ」として蓄積する。

| 項目       | malloc                          | sparse                          |
|------------|---------------------------------|---------------------------------|
| 削除操作   | 疎行列版削除操作 O(1)、即座に完了 | O(log E)、ゴミ蓄積              |
| メモリ     | 固定 20MB                       | 初期 0.3MB → 徐々に増加         |
| 走査速度   | O(N²)                           | O(E) だがゴミ分遅くなる         |

## 最悪ケース

- 長時間学習でゴミが数万件蓄積 → 走査が2-3倍遅くなる可能性

## 対策

- 定期的に `prune()` を呼ぶ（100エポックに1回程度）

## 結論

- 通常使用では問題なし。長時間学習時は `prune()` で解決可
